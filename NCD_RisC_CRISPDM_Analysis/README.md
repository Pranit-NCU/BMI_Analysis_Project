PROJECT OVERVIEW
----------------------------------------------------------------------

This project follows the CRISP-DM (Cross-Industry Standard Process for Data Mining)
framework to analyze global trends in obesity and diabetes prevalence over time,
focusing on India, the United Kingdom, and global aggregates. 

Key objectives:
1. Examine how mean BMI and obesity prevalence have changed over time (1990–2022).
2. Compare obesity and diabetes prevalence between countries.
3. Assess global correlations between obesity and diabetes.
4. Explore gender differences in these trends.
5. Apply statistical models (Linear Regression, ANOVA) to study associations.

The analysis is based on datasets from the Non-Communicable Disease Risk Factor 
Collaboration (NCD-RisC), specifically:
- BMI_age_standardised_country.csv
- Diabetes_age_standardised_countries.csv

INSTRUCTIONS TO RUN ANALYSIS
----------------------------------------------------------------------

1. Open R Cloud or RStudio (connected to your GitHub repository if applicable).

2. Load the ProjectTemplate package:
      library(ProjectTemplate)

3. Load the project:
      load.project()

   This will automatically run the scripts in `/munge/` and load all
   datasets into your R environment.

4. To verify data loading:
      ls()
   You should see objects like:
      bmi, diab, merged_countries, merged_global, joined_bmi_diabetes

5. To view the report:
      Knit or render the R Markdown file located in:
         reports/CRISPDM_Report.Rmd

   Example command:
      rmarkdown::render("reports/CRISPDM_Report.Rmd")

6. The report will be generated as:
      - CRISPDM_Report.html  (default output)
      or
      - CRISPDM_Report.pdf   (if you change the YAML output format)

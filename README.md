# BMI_Analysis_Project
Global Health Analysis

MAS8600_MAS8505_01_formative_report

Key objectives:
1. Examine how mean BMI and obesity prevalence have changed over time (1990–2022).
2. Compare obesity and diabetes prevalence between countries.
3. Assess global correlations between obesity and diabetes.
4. Explore gender differences in these trends.
5. Apply statistical models (Linear Regression) to study associations and provide investigative conclusion.
